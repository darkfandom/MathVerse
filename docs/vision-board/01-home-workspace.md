## Interaction States

### Card
- **Default**: `#12121E` bg, `#2A2A3E` border, no shadow
- **Hover**: `#1A1A2E` bg, accent-tinted border, `0 4px 20px rgba(accent, 0.1)` shadow, `translateY(-2px)`
- **Pressed**: `scale(0.98)`, `#12121E` bg
- **Active**: Subtle left border accent, slightly brighter

### Sidebar Button
- **Default**: Icon `#4A4A64`, transparent bg
- **Hover**: Icon `#E8E8F0`, bg `rgba(255,255,255,0.04)`
- **Active**: Icon `#4A9EFF`, left 3px bar `#4A9EFF`, bg `rgba(74,158,255,0.06)`

## Accessibility

- All interactive elements have minimum 44x44px hit target
- Focus ring: 2px `#4A9EFF` with 2px offset
- Contrast ratio minimum: 4.5:1 for text
- Screen reader labels on all icons
- Keyboard navigation: Tab through sidebar → main content → status bar
